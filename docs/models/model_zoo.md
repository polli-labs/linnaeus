# Model Zoo

> Status: no verified public Linnaeus model artifacts are published from this
> repo today.

This page tracks release posture, not a live registry.

## Current Release Posture

- **Published now:** none
- **Retired plan:** the older North American `mFormerV1_sm` suite described in
  earlier docs is no longer the release plan
- **Current release candidate shape:** bundle-first `DINOv3MultiHead` artifacts
  from the active DINOv3 vNext line
- **Earliest plausible public window:** late April or early May 2026, if
  experiment, packaging, and documentation gates all pass

Treat that window as an estimate, not a promise.

## What A First Public Artifact Set Is Expected To Look Like

When Linnaeus does publish public artifacts, this page should list at least:

- architecture family
- taxonomic scope
- bundle format and version
- metadata expectations
- artifact URI
- evaluation receipt or release note that backs the artifact

Until that registry exists, use the inference docs to understand the contract
and assume nothing about artifact availability.

## Historical Note

The repo still contains mFormer-era code, configs, and historical provenance
pages. Those are useful for understanding how the project got here. They should
not be read as the current public model roadmap.
